# Palindrome Number

**Difficulty:** `Easy`

## Problem

Given an integer x, return true if x is a palindrome, and false otherwise.

An integer is a palindrome when it reads the same forward and backward.

- For example, 121 is a palindrome, but 123 is not.
- Negative numbers are never palindromes, since the minus sign only appears on one side.
- A number ending in 0 (other than 0 itself) is never a palindrome, since a palindrome cannot start with a leading 0.

Read x from standard input, and print true or false to standard output.

## Examples

### Example 1

**Input**
```
x = 121
```
**Output**
```
true
```

**Explanation:** 121 reads the same forward and backward.

### Example 2

**Input**
```
x = -121
```
**Output**
```
false
```

**Explanation:** Reversed, it would read 121-, which is not a valid palindrome.

### Example 3

**Input**
```
x = 10
```
**Output**
```
false
```

**Explanation:** Reversed, it would read 01, which does not equal 10.
